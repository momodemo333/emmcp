# EM-MCP improvement backlog

Ce répertoire sert à capturer les frictions rencontrées lors de l’utilisation réelle du MCP Dolibarr/EM-MCP par Arnold ou d’autres agents.

Quand un appel MCP échoue, retourne une forme de données confuse, nécessite un contournement, consomme trop de contexte, manque d’un outil haut niveau, ou expose un comportement Dolibarr/API illogique, créer une note `YYYY-MM-DD-sujet.md` ici.

Chaque note devrait contenir :

- contexte d’usage ;
- outil MCP concerné ;
- entrée sanitizée ;
- résultat/erreur observé ;
- comportement attendu ;
- contournement éventuel ;
- idée d’amélioration côté module.

Ne pas y stocker de secrets, clés API, mots de passe, données sensibles complètes ou dumps clients inutiles.
