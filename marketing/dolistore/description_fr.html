emMCP — Connectez votre assistant IA à votre Dolibarr

Vous utilisez déjà un assistant IA au quotidien. emMCP lui donne accès à votre Dolibarr : vos tiers, vos factures, vos produits, vos commandes, vos projets, vos documents. Vous posez vos questions et donnez vos instructions dans votre assistant habituel, et il travaille directement dans votre ERP.

Aucun assistant à apprendre, aucune interface supplémentaire : vous gardez l'outil que vous utilisez déjà.

⚡ Trois étapes, et c'est parti

  1. Installez et activez le module comme n'importe quel module Dolibarr.
  2. Réglez les permissions de l'utilisateur qui sera associé à l'assistant. C'est tout le paramétrage : l'assistant héritera exactement de ses droits.
  3. Ajoutez le connecteur dans votre client IA en collant l'URL affichée par le module.

La page de configuration vous donne l'URL, la commande et le fichier de configuration prêts à copier, selon le client que vous utilisez. Comptez quelques minutes.

🔌 Compatible avec les clients que vous utilisez déjà

  • claude.ai (web et application) — connecteur personnalisé avec authentification OAuth : vous vous connectez avec votre compte Dolibarr et donnez votre consentement. Aucune clé à copier-coller.
  • Claude Code — une seule commande à exécuter.
  • API Anthropic et tout client MCP acceptant le transport HTTP.

💬 Ce que votre assistant peut faire

Une vingtaine d'outils couvrent le quotidien de Dolibarr :

  • Consulter et chercher — « Quelles factures de ce client sont impayées ? », « Retrouve la commande de la semaine dernière pour Dupont »
  • Créer et modifier — tiers, devis, factures, commandes, produits, projets, avec leurs lignes
  • Enchaîner les actions métier — valider un devis, le transformer en commande, générer le PDF
  • Gérer les documents — lister, téléverser, télécharger, générer les PDF depuis les modèles Dolibarr
  • Travailler avec vos champs personnalisés, vos contacts liés, votre suivi de temps

Les outils passent par l'API REST de Dolibarr : ce que votre assistant peut voir et faire correspond exactement à ce que l'utilisateur associé peut voir et faire dans l'interface.

🔒 Vos permissions Dolibarr font foi

C'est le principe de fond du module. L'assistant n'a pas de droits propres : il agit au nom d'un utilisateur Dolibarr, avec ses permissions, module par module. Vous voulez un assistant en lecture seule pour la comptabilité ? Créez un utilisateur en lecture seule. Vous voulez qu'il puisse créer des factures mais pas toucher aux salaires ? C'est un réglage de permissions, celui que vous maîtrisez déjà.

L'authentification se fait par OAuth 2.1 (avec PKCE et rotation des jetons) ou par clé API selon le client, et vous pouvez révoquer un accès à tout moment.

📊 Requêtes SQL en lecture seule — en option, désactivé par défaut

Pour les analyses que l'API REST ne couvre pas — agrégats sur plusieurs années, croisements de tables, tableaux de bord sur mesure — le module peut ouvrir un accès SQL strictement en lecture. Il est éteint par défaut et protégé par plusieurs verrous indépendants :

  • un interrupteur global, éteint à l'installation ;
  • une permission Dolibarr, accordée à personne par défaut ;
  • une validation nominative, utilisateur par utilisateur ;
  • un garde-fou spécifique aux environnements multi-sociétés.

Tant qu'une seule de ces conditions manque, les outils SQL n'apparaissent même pas dans la liste des outils du client.

Chaque requête est analysée par un lexeur et un analyseur syntaxique SQL avant d'atteindre le serveur : seules les requêtes de consultation passent. Les écritures, les commandes de structure, les instructions multiples et les colonnes de mots de passe ou de clés sont refusées — y compris quand un mot-clé d'écriture est dissimulé dans une chaîne de caractères. Les jointures, sous-requêtes, UNION et agrégats fonctionnent normalement. Nombre de lignes, durée et taille de réponse sont plafonnés, et chaque requête est journalisée.

🛠️ Rien à héberger, rien à surveiller

emMCP fonctionne dans votre Dolibarr existant, comme n'importe quelle page PHP. Pas de service à lancer, pas de port à ouvrir, pas de conteneur à maintenir. Si votre Dolibarr répond, votre serveur MCP répond.

⚙️ Prérequis

  • Dolibarr 16 ou supérieur, PHP 8.1 ou supérieur
  • Le module API REST de Dolibarr activé
  • Un accès HTTPS à votre instance depuis le client IA
  • Un compte auprès du fournisseur d'IA de votre choix — le module ne facture aucun abonnement supplémentaire
