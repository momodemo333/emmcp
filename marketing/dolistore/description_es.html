emMCP — Conecte su asistente de IA a su Dolibarr

Ya utiliza un asistente de IA a diario. emMCP le da acceso a su Dolibarr: sus terceros, facturas, artículos, pedidos, proyectos y documentos. Usted plantea sus preguntas y da sus instrucciones en el asistente de siempre, y este trabaja directamente en su ERP.

Ningún asistente nuevo que aprender, ninguna interfaz adicional: conserva la herramienta que ya usa.

⚡ Tres pasos y listo

  1. Instale y active el módulo, como cualquier otro módulo de Dolibarr.
  2. Configure los permisos del usuario en cuyo nombre actuará el asistente. Esa es toda la configuración: el asistente hereda exactamente esos derechos.
  3. Añada el conector en su cliente de IA pegando la URL que muestra el módulo.

La página de configuración le entrega la URL, el comando y el archivo de configuración listos para copiar, según el cliente que utilice. Cuestión de minutos.

🔌 Compatible con los clientes que ya utiliza

  • claude.ai (web y aplicación) — conector personalizado con autenticación OAuth: inicia sesión con su cuenta Dolibarr y da su consentimiento. Ninguna clave que copiar.
  • Claude Code — un solo comando.
  • API de Anthropic y cualquier cliente MCP con transporte HTTP.

💬 Lo que su asistente puede hacer

Una veintena de herramientas cubren el día a día de Dolibarr:

  • Consultar y buscar — «¿Qué facturas de este cliente están pendientes?», «Encuentra el pedido de la semana pasada para Dupont»
  • Crear y modificar — terceros, presupuestos, facturas, pedidos, artículos, proyectos, con sus líneas
  • Encadenar acciones de negocio — validar un presupuesto, convertirlo en pedido, generar el PDF
  • Gestionar documentos — listar, subir, descargar, generar PDF desde sus plantillas de Dolibarr
  • Trabajar con sus campos personalizados, contactos vinculados e imputación de tiempos

Las herramientas pasan por la API REST de Dolibarr: lo que su asistente puede ver y hacer coincide exactamente con lo que el usuario asociado puede ver y hacer en la interfaz.

🔒 Mandan sus permisos de Dolibarr

Es el principio de fondo del módulo. El asistente no tiene derechos propios: actúa en nombre de un usuario Dolibarr, con sus permisos, módulo a módulo. ¿Quiere un asistente de solo lectura para contabilidad? Cree un usuario de solo lectura. ¿Que pueda emitir facturas pero nunca ver las nóminas? Es un ajuste de permisos, el mismo que ya domina.

La autenticación se realiza mediante OAuth 2.1 (con PKCE y rotación de tokens) o con una clave API según el cliente, y puede revocar un acceso en cualquier momento.

📊 Consultas SQL de solo lectura — opcional, desactivado por defecto

Para los análisis que la API REST no cubre — agregados de varios años, cruces de tablas, cuadros de mando a medida — el módulo puede abrir un acceso SQL estrictamente de lectura. Viene desactivado y está protegido por varios cierres independientes:

  • un interruptor global, apagado tras la instalación;
  • un permiso Dolibarr, que por defecto no tiene nadie;
  • una validación nominal, usuario por usuario;
  • una protección específica para entornos multiempresa.

Mientras falte una sola de esas condiciones, las herramientas SQL ni siquiera aparecen en la lista de herramientas del cliente.

Cada consulta pasa por un analizador léxico y un analizador sintáctico SQL antes de llegar al servidor: solo pasan las consultas de lectura. Las escrituras, los comandos de estructura, las instrucciones múltiples y las columnas de contraseñas o claves se rechazan, incluso cuando una palabra clave de escritura se esconde dentro de una cadena de texto. Las uniones, subconsultas, UNION y agregados funcionan con normalidad. El número de filas, la duración y el tamaño de la respuesta están limitados, y cada consulta queda registrada.

🛠️ Nada que alojar, nada que vigilar

emMCP funciona dentro de su Dolibarr existente, como cualquier página PHP. Ningún servicio que arrancar, ningún puerto que abrir, ningún contenedor que mantener. Si su Dolibarr responde, su servidor MCP responde.

⚙️ Requisitos

  • Dolibarr 16 o superior, PHP 8.1 o superior
  • Módulo API REST de Dolibarr activado
  • Acceso HTTPS a su instancia desde el cliente de IA
  • Una cuenta con el proveedor de IA que elija — el módulo no añade ninguna suscripción propia
